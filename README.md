
# Tic-Tac-Toe Game Using Python Tkinter

A two-player Tic-Tac-Toe desktop game built with Python's
Tkinter GUI library.

## Features
- Interactive 3x3 game board
- Two-player gameplay (X and O)
- Automatic win detection
- Draw detection
- Restart button
- Prevents moves in occupied cells

## Technologies
- Python
- Tkinter
- GUI programming
- Functions and lists

## Requirements
Python 3 with Tkinter support.

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   python tic_tac_toe.py

## How to Play
Players take turns selecting empty squares.
The first player to align three marks horizontally,
vertically, or diagonally wins.

If all nine squares are filled without a winner,
the game ends in a draw.
